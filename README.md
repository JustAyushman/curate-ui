# Curate - UI/UX Design Implementation

A beautiful, responsive masonry grid layout capturing a premium, modern design aesthetic. This project was built to translate a sophisticated UI/UX design into code, featuring an elegant image layout, clear typography, and a polished user interface.

## ✨ Features

- **Responsive Masonry Grid:** Implemented a seamless multi-column layout for displaying creative insight cards.
- **Premium Aesthetics:** Clean typography, minimalist design touches, subtle shadows, and neat borders.
- **Micro-interactions:** Interactive hover states on cards that reveal additional features (like the "Curate" tag).
- **Tailwind CSS:** Fully styled using Tailwind CSS for a utility-first, easily editable structure.
- **Lightweight:** Pure HTML setup needing zero complicated build steps.

## 🛠️ Built With

- **HTML5**
- **Tailwind CSS** (via CDN)
- **Google Fonts** (Inter)
- **Remix Icons**

## 💡 About the Creation Process

This project represents the realization of a beautiful design concept into functional web code. I brought this idea to life with the assistance of **Antigravity**, an AI coding assistant by Google DeepMind, who helped me build and refine the frontend layout seamlessly using HTML and Tailwind CSS. 

## 🚀 Getting Started

Simply clone this repository and open `index.html` in your favorite web browser. No compilation or installation steps are required!

```bash
git clone https://github.com/JustAyushman/curate-ui.git
cd curate-ui
```

Then, double-click `index.html` to view the project locally.
